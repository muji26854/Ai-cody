# Cody Android — v0.1.0

This is the first working Android prototype of Cody, a voice-controlled phone assistant.

## What works

- Voice input using Android SpeechRecognizer
- Spoken responses using Android TextToSpeech
- Open YouTube
- Open Chrome
- Google search by voice
- Back
- Home
- Scroll up/down through AccessibilityService
- Accessibility-service setup button

## Build

Open this folder in Android Studio.

Use:
- JDK 17
- Android SDK 35
- Gradle wrapper can be generated by Android Studio if it is missing.

Then:
1. Sync Gradle.
2. Build > Make Project.
3. Run on an Android phone.
4. Grant microphone permission.
5. Open Cody and tap "Enable Cody Accessibility".
6. Enable Cody in Android Accessibility settings.
7. Return to Cody and tap Speak.

Try:
- "Open YouTube"
- "Open Chrome"
- "Search for Minecraft"
- "Go back"
- "Go home"
- "Scroll down"

## Next development stage

The command processor is intentionally simple. The next version should replace it with an AI planner that turns natural-language requests into safe structured actions, while keeping confirmation gates for sensitive actions.

Do not use AccessibilityService to bypass Android security, privacy controls, CAPTCHAs, passwords, or other access restrictions.
